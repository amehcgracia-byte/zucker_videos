# Menús de escritorio

La aplicación conserva Acerca de Zucker Editor, cerrar/ocultar, pantalla completa y los controles nativos de copiar/pegar. Los servicios externos de macOS (incluidos asistentes instalados por otras aplicaciones) se ocultan únicamente en el menú de Zucker; no se modifican preferencias del sistema.

| Menú | Accesos |
| --- | --- |
| Archivo | Nuevo proyecto, historial, archivos y logotipo personal, selector de modalidad |
| Montaje | Parámetros, encuadres 360, Reel, Backstage, Medley, iniciar, progreso, revisión, reemplazo, aprobación Backstage, render y cancelación |
| Subtítulos y superposiciones | Editor, panel de importación SRT/LRC, transcripción, exportación SRT, incrustación, imágenes/vídeos/logotipo, reutilización y duplicación |
| Reproducción | Reproducir/pausar, avanzar/retroceder un fotograma, ampliar previsualización |
| Resultado | Vídeo final y ubicación en el ordenador |
| Herramientas | Buscar actualizaciones, tema, detalles, informe y registros |

Los accesos a paneles abren los controles existentes; las importaciones de subtítulos, imágenes y vídeos se realizan desde sus selectores dentro del panel. Las opciones conservan las restricciones del modo y estado del proyecto y las confirmaciones existentes. YouTube y Medley conservan su recorrido directo al resultado.

## Actualizaciones

«Buscar actualizaciones…» aparece en Herramientas y en el menú de la aplicación de macOS. Permite repetir una consulta después de una comprobación anterior o de un fallo de conexión. Informa si no hay novedades. No reinicia una descarga o instalación activa. Descargar e instalar siguen exigiendo consentimiento y una aplicación sin trabajos pendientes, según las protecciones del actualizador existente.

## Validación

Pruebas de callbacks nativos, despacho JavaScript, acciones deshabilitadas, restricciones de proyecto y reconsulta del actualizador. Suite de actualizador y menús: 29 pasan, 2 omitidas por plataforma. Sintaxis JavaScript comprobada con Node.

Esta revisión se prepara en el repositorio mientras sigue el render de la aplicación instalada 2.6.0. No se reemplaza ni se reinicia esa aplicación durante el trabajo del usuario. La comprobación visual del menú nativo corresponde a la siguiente instalación.
